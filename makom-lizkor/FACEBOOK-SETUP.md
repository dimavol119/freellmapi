# חיבור פייסבוק — שלב ההגדרה המשותפת

התשתית נכתבה, אך ההתחברות לפייסבוק כבויה עד להשלמת ההגדרה ובדיקת אמת. אין ייבוא אוטומטי של חברים או ימי הולדת מפייסבוק.

1. לפתוח https://developers.facebook.com/apps/ בחשבון של בעל האתר וליצור אפליקציה המתאימה ל־Facebook Login. בעל החשבון משלים בעצמו אימותים ואישור תנאים אם נדרשים.
2. אפשר למסור את App ID (אינו סוד). אין לשלוח App Secret או סיסמת Facebook בשיחה. את הסוד יש להוסיף רק בשדה סודות מאובטח של האתר, בהמשך ההגדרה.
3. כתובת האתר: https://makom-lizkor-dima.dimavol11.chatgpt.site
4. כתובת חזרה מדויקת לרשימת Valid OAuth Redirect URIs:
   https://makom-lizkor-dima.dimavol11.chatgpt.site/api/auth/facebook/callback
5. ההרשאות המבוקשות: public_profile,email בלבד. אין בקשה לרשימת חברים או ליום הולדת.
6. לפני פתיחה לציבור: להשלים מדיניות פרטיות ודרך מחיקת נתונים אמיתית, פרטי בעל האתר והדרישות שמופיעות בלוח הבקרה של Meta. אין לפרסם כתובות מדיניות שאינן קיימות.
7. סודות/הגדרות שרת נדרשים: FACEBOOK_APP_ID, FACEBOOK_APP_SECRET, FACEBOOK_GRAPH_VERSION (הגרסה הנתמכת שתבחר בלוח הבקרה), FACEBOOK_SITE_ORIGIN (כתובת האתר ללא לוכסן בסוף). להפעיל FACEBOOK_LOGIN_ENABLED=true רק לאחר בדיקת ההגדרה.
8. לבדוק תחילה עם תפקיד בדיקה מורשה ב־Meta: כניסה חדשה, ביטול, חזרה לאתר וחיבור לחשבון קיים. רק לאחר מכן להשלים את דרישות Meta לגישה ציבורית.

חשבון עם אותו אימייל אינו מקושר אוטומטית. המשתמש נכנס קודם באמצעות סיסמת האתר, ואז בוחר ״המשך עם פייסבוק״ בהגדרות. זה מונע השתלטות על חשבון באמצעות התאמת אימייל בלבד.

נתוני פייסבוק נשמרים כמזהה אפליקציה המקושר למשתמש. אסימון הגישה אינו נשמר. סשנים מאובטחים נשארים בצד השרת ובעוגיית HttpOnly. התחברות זו מיועדת כרגע לאתר; חיבור לאפליקציות native דורש בהמשך הגדרת SDK וכתובות חזרה נפרדות.
