# מקום לזכור כאפליקציה

## 1. אפליקציה מהאתר (PWA) – פעיל, חינם, אייפון + גלקסי + מחשב
אחרי פרסום האתר, אפשר להתקין אותו כאפליקציה ישירות מהדפדפן:
- **אייפון:** Safari → כפתור השיתוף → „הוספה למסך הבית”.
- **גלקסי:** Chrome או Samsung Internet → תפריט → „התקנת אפליקציה” / „הוספה למסך הבית”.
- **מחשב:** Chrome או Edge → סמל ההתקנה בשורת הכתובת.

ההסבר מופיע גם באפליקציה עצמה, בהגדרות ← „התקנה כאפליקציה”.

הקבצים נמצאים ב־`mobile-source/public/`: `manifest.webmanifest`, `sw.js`, האייקונים ותבנית `index.html`. ייצוא Expo מעתיק אותם אוטומטית.

**כלל פרטיות:** ה־service worker שומר רק את מעטפת האפליקציה והאייקונים. כל מה שתחת `/api/` (חשבון, פריטים, גרסאות) לא נשמר בזיכרון המטמון אף פעם. בדיקה אוטומטית ב־`tests/account.test.cjs` שומרת על הכלל הזה.

## 2. אפליקציית Android (APK) – חינם, להתקנה ישירה בגלקסי
הקוד מוכן: אייקון, מסך פתיחה ומזהה `com.makomlizkor.app` מוגדרים ב־`app.json`. גם חבילות Android ו־iOS נבנות בהצלחה (`npx expo export --platform android --platform ios`).

בנייה בחינם דרך EAS. נדרש חשבון Expo חינמי שלך, בלי כרטיס אשראי:
```sh
cd mobile-source
npx eas-cli login
npx eas-cli build -p android --profile preview
```
בסוף הבנייה מתקבל קישור לקובץ APK. פותחים אותו בגלקסי ומאשרים „התקנה ממקור לא ידוע”.

לפני פרסום ראשון בחנות אפשר עדיין לשנות את המזהה `com.makomlizkor.app`. אחרי הפרסום הוא קבוע.

הערות:
- פרסום ב־Google Play עולה 25$ חד־פעמית. לכן הוא לא מופעל, לפי הדרישה לאפס עלות.
- באפליקציה הנייטיבית הכניסה עם Google כבויה (היא פועלת רק באתר). אימייל וסיסמה פועלים.
- תזכורות אמיתיות במכשיר (התראות) קיימות רק באפליקציה הנייטיבית. באתר מייצאים אירוע ליומן.

## 3. אייפון כאפליקציית App Store – לא מופעל
נדרש חשבון Apple Developer בעלות 99$ לשנה, וזה בניגוד לדרישת אפס העלות. באייפון משתמשים באפליקציה מהאתר (סעיף 1).
