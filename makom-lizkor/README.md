# מקום לזכור

אתר ומקור אפליקציית Expo עבור Android, iOS ודפדפן.

## יכולות
- הרשמה באמצעות אימייל וסיסמה של 12 תווים לפחות, התחברות ויציאה.
- מרחב פרטי לכל חשבון, עם שמירה בשרת וגישה ממכשירים אחרים.
- שימוש מקומי ללא הרשמה; העברת פריטים קיימים לחשבון בכפתור מפורש בהגדרות.
- עברית, רוסית ואנגלית, נושאים, חיפוש רגיל, לימודים, תמונות ותאריכים.
- גיבוי קובץ ידני ל־Google Drive או iCloud דרך שיתוף/הורדה.
- תזכורות באפליקציה לפי הרשאות המכשיר; באתר ייצוא אירוע ליומן.
- אין שימוש ב־AI או ב־API בתשלום.

## מגבלות גרסת הניסיון
שחזור סיסמה במייל מוכן אך כבוי עד הגדרת שירות אימייל (ראה RESET-SETUP.md). אין עדיין אימות אימייל. אין שיתוף נתונים בין חשבונות.
שמירת מרחב לחשבון מוגבלת ל־20 MB. שינויים משני מכשירים מתאחדים אוטומטית לפי פריט ושדה, והאפליקציה מתרעננת כשחוזרים אליה.
אין עדיין APK/IPA חתומים, בדיקות על טלפונים פיזיים או התראות רקע באתר.

## מבנה ופרסום
השרת הוא Vinext עם D1 לחשבונות וסשנים ו־R2 לתוכן פרטי. קוד האפליקציה נמצא ב־mobile-source.
מיגרציות Drizzle נשמרות עם המקור. אין להעתיק נתוני QA, תיקיות runtime או קבצי env לפרסום.
